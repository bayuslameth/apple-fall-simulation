Cara Bermain

Gunakan simulasi ini untuk mengamati perubahan posisi, kecepatan, dan percepatan apel saat jatuh.

  • Tekan Mulai atau Space untuk menjalankan dan menjeda simulasi.
  • Gunakan slider speed untuk mempercepat atau memperlambat waktu simulasi.
  • Ubah gravitasi untuk membandingkan efek percepatan terhadap kecepatan jatuh.
  • Amati platform Bulan, Bumi, dan Jupiter untuk melihat gravitasi berubah otomatis.
  • Arahkan apel ke keranjang target untuk menambah skor.
  • Gunakan W, A, S, D untuk bergerak, Shift untuk berlari, klik kanan + drag atau tombol panah untuk melihat sekitar.
  • Tekan R untuk reset apel ke posisi awal.
